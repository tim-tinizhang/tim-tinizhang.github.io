# Tin I (Tim) Zhang — Academic Website

A responsive, single-page academic website for GitHub Pages.

## Navigation order

Home → Research → Biography → PAPER Workshop → Contact → CV

The CV navigation controls scroll to the CV section. The **Download CV** button in that section opens `assets/files/Tin-I-Zhang-CV.pdf` in a new tab.

## Files

- `index.html`: complete single-page website
- `assets/css/style.css`: typography, responsive layout, glass UI, and controls
- `assets/js/main.js`: smooth section navigation, active-section tracking, mobile menu, and restrained reveal effects
- `assets/images/favicon.svg`: blue glass “T” icon
- `assets/files/Tin-I-Zhang-CV.pdf`: replace with the current CV while preserving the filename
- `research.html`, `biography.html`, `paper-workshop.html`, `contact.html`, `cv.html`: compatibility redirects to the matching section

## Publish

Use the repository name `tim-tinizhang.github.io`. Upload these files to the repository root and enable GitHub Pages from `main` and `/(root)`.
